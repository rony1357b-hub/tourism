# Rony Travel — redesigned travel website

## What's inside
- `index.html` — hero, stats, brand introduction and responsive navigation
- `about.html` — story, mission, timeline and FAQ accordion
- `tours.html` — 9 packages with category filters, live search and booking modal
- `destinations.html` — destination cards and custom-trip CTA
- `services.html` — service cards and clear calls to action
- `contact.html` — polished trip-request form with demo success state
- `assets/styles.css` — one shared design system (colors, typography, responsive layout)
- `assets/script.js` — mobile menu, dark mode, reveal animations, counters, filters, FAQ, modal and demo form
- `assets/rony-traveler.jpg` — your uploaded travel image used as a local hero image

## Run it
Open `index.html` in a browser. No build step is required.

## Customize
The shared theme is at the top of `assets/styles.css` under `:root`. Change the CSS variables to quickly recolor the entire site.

The external destination/tour images use Unsplash URLs, so those images need internet access. The main uploaded image is bundled locally.

## Important
The contact form is a front-end demo. Connect it to a backend/email service before using it for real submissions.
